# Відео KMA Quest

На момент складання архіву окремих відеофайлів немає: сцени показуються за допомогою canvas-анімації в самій грі.

Тут можна розмістити MP4 (H.264) з такими назвами:

- `p1_admission.mp4` — вступна сцена
- `ch2_lecture.mp4` — лекція
- `ch3_history.mp4` — історична сцена
- `final.mp4` — фінал
- `story_girkyi.mp4`, `story_puzatka.mp4`, `story_kfs.mp4` — короткі сторіс

Якщо файл відсутній, гра використовує вбудовану анімацію. Див. `src/engine.js`.
