# Озвучення KMA Quest

Окремі записи голосів поки що не створені: вихідний артефакт Claude не містив аудіозаписів реплік.

Покладіть MP3 з ідентифікаторами, вказаними в `README.md` у корені проєкту та в `src/story.js`. Гра підхопить їх автоматично. Без цих файлів діалоги залишаються текстовими зі звуками друку.
